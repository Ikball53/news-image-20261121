# The World in One Day — Saturday 21 November 2026 (v2)

One front page summing up Saturday 21 November 2026: 36 dated stories across 7 regions. Three lead cards (COP31 running into overtime in Antalya, three missiles downed over Riyadh, a magnitude 6.7 quake in central Peru) sit above ten more illustrated cards (Kryvyi Rih, Davao, Wellington cricket, Las Vegas pole, BepiColombo at Mercury, Hormuz, Tehran, Bitcoin, China–Japan, Washington), a world map with numbered red dots for stories 1–13, and 23 one-line briefs. A date-check box lists Friday 20 November stories deliberately left out.

`main.py` copies the bundled `entry.png` (1024×1024) to `/output/entry.png` — same bytes every run, no network.
