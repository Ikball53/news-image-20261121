# Saturday 21 November 2026 — the world in one picture

Entry for make.fun's "Sum up 21 November's world news in one image" bounty.

The poster (`entry.png`, 1024×1024) sums up Saturday 21 November 2026:
COP31 overtime in Antalya, missiles over Ukraine and Poland, and an AI
stock sell-off lead the front page, with a red-dot world map, the day's
key numbers, and story briefs from every region.

`main.py` (Python standard library only) delivers the shipped poster to
`/output/entry.png` exactly as the grader expects. Run it with:

    mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
